## 🌟 优化1：双语标题呈现

### 功能描述

所有英文信源（路透社/BBC/SCMP/卫报/CNN/NYT等）的新闻标题采用**双语紧凑格式**显示。

### 显示效果

```

   外交部发言人就中美关系答记者问

英文信源标题（新）:
   Ukraine's envoy to US: We need missiles    ← 深蓝色（英文原题）
   乌克兰驻美大使紧急呼吁：我们需要导弹        ← 灰色（中文翻译）
```

### 技术实现

1. **WebFetch Prompt强化**
   - 明确要求返回"英文原标题 + 中文翻译"
   - 格式示例："English Title 中文翻译"
2. **数据结构扩展**
   ```python

     'title': '乌克兰驻美大使紧急呼吁',  # 中文标题（主字段）

     'title_display': "Ukraine's envoy... 乌克兰驻美大使...",  # 完整双语
   }
   ```
3. **智能解析算法**
   - 新增 `_parse_bilingual_title()` 方法
   - 自动识别并分离中英文部分
   - 支持多种分隔模式

### 使用场景

- ✅ 直接复制英文标题到Google搜索相关报道
- ✅ 快速识别文章原始出处
- ✅ 保持专业性（国际场合通常使用英文标题引用）

## 🎯 优化2：按重要性智能排序

### 功能描述

新闻列表不再按媒体来源分组，而是**按重要性降序排列**，确保最重要信息第一时间可见。

### 优先级体系（4级）

| 优先级       | 权重   | 显示样式    | 触发条件               |
| --------- | ---- | ------- | ------------------ |
| **⭐ 元首级** | 1000 | 金色+渐变背景 | 中美元首/最高层会晤、通话、国事访问 |
| **高**     | 100  | 红色粗体    | 重要外交动态、重大冲突、经济制裁   |
| **中**     | 10   | 橙色      | 一般国际新闻             |
| **低**     | 1    | 绿色      | 体育娱乐等              |

### 排序规则

```javascript
// 双重排序：先按优先级，同优先级按重要性
function sortByPriority(data) {
    return data.sort((a, b) => {
        // 第一排序键：priority权重
        const priorityDiff = PRIORITY_WEIGHT[b.priority] - PRIORITY_WEIGHT[a.priority];
        if (priorityDiff !== 0) return priorityDiff;

        // 第二排序键：importance权重
        return IMPORTANCE_WEIGHT[b.importance] - IMPORTANCE_WEIGHT[a.importance];
    });
}
```


## 🚀 优化3：信源扩展与数量提升

### 当前问题分析

**基础采集失败原因诊断**：

```
✅ 人民网: 连接成功 (129KB内容)
✅ 环球网: 连接成功 (12KB内容)
✅ 国际在线: 连接成功 (160KB内容)
❌ 新华网: 404错误（URL失效）
```

**结论**：网络连接正常，问题出在**内容提取逻辑过于简单**

### 解决方案：WebFetch优先策略

#### 信源扩展：4个 → 10个

**保留的4个核心信源**：

1. 路透社 (Reuters) - 8条/次
2. BBC News - 6条/次
3. 南华早报 (SCMP) - 6条/次
4. 卫报 (The Guardian) - 5条/次

**新增6个权威信源**：  
5\. **CNN** - 美国政治/全球冲突 (5条/次)  
6\. **纽约时报 (NYT)** - 深度分析/中美关系 (4条/次)  
7\. **半岛电视台 (Al Jazeera)** - 中东/全球南方视角 (4条/次)  
8\. **Politico** - 外交政策/贸易谈判 (3条/次)  
9\. **华盛顿邮报 (Washington Post)** - 美国外交/民主治理 (3条/次)  
10\. **美联社 (AP News)** - 突发新闻快讯 (4条/次)

**预期总数量**：

- WebFetch英文信源: ~48条 (10个 × 平均4.8条)
- 基础采集中文信源: ~10-15条 (修复后)
- **总计目标: 40-60条高质量新闻**
