三、采集与更新机制
🏗️ 双层采集架构
第1层 基础采集 (requests)
中文信源：人民网、外交部、环球网等17个
✅ 速度快、稳定性高
第2层 WebFetch API 补充
英文权威信源：路透社/BBC/SCMP/CNN/NYT等8-10个
✅ 绕过反爬虫、高质量、实时性好
🛡️ 质量控制体系
  • 自动去重：标题相似度算法移除重复文章
  • URL验证：强制覆盖率 ≥ 95%（实际已达100%）
  • 智能评分：基于内容分析自动计算 priority_score
  • 分类标注：自动归入 6+ 个话题类别
  • 元首级识别：自动检测中美元首/高层新闻并标记金色徽章
🕐 更新频率：每日手动更新 2 次 — 🌅 早间 09:30（隔夜欧美要闻） / 🌇 下午 17:00（当日亚洲动态），每次约 3-5 分钟，产出 30-60 条精选新闻

五、新闻筛选标准
✅ 内容质量标准
  • 仅权威信源：严禁自媒体/营销号/社交平台内容
  • 优先原创报道：转载/聚合类内容降权处理
  • 事实准确性：追求客观事实，避免煽动性标题党
  • 实质内容门槛：摘要不少于150字，确保信息量
  • 元数据完整：标题、日期、来源、URL为必填字段
