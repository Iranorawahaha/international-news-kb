## 紧急修复：前端数据加载失败问题（反复出现）

2. 检查 `EMBEDDED_CONFIG` → undefined（因为实际是 window.NEWS_CONFIG）

4. file:// 协议 CORS 限制 → fetch 失败
5. 显示 "配置文件加载失败，使用默认配置"
6. 新闻数据同样无法加载 → 页面空白

### 修复方案

3. 正确处理 `window.NEWS_DATA` 的两种可能格式：

```python
if isinstance(existing_data, list):

    existing_news = existing_data.get('news', [])  # v1格式
```
