## 修复任务：前端加载失败问题 + 数据导出（17:25-17:35）

### 问题描述
用户反馈：网页打开后显示"配置文件加载失败"，数据表格为空，但 data/news-data.json 中已有45条数据。

### 根本原因
前端JS使用 `fetch('data/config.json')` 和 `fetch('data/news-data.json')` 加载数据，在以下场景失败：
1. 直接打开HTML文件时存在跨域限制
2. HTTP服务器CORS配置问题
3. 网络延迟或路径问题

### 修复方案（三层保障机制）

#### 第1层：内嵌数据（核心修复）✅
**新增文件**: `js/embedded-data.js` (52KB)
- 将30个信源配置和45条新闻数据直接嵌入JavaScript变量
- 页面加载时优先读取内嵌数据，无需任何网络请求
- **彻底解决"配置文件加载失败"问题**

**实现方式**：
```javascript
// js/embedded-data.js
const EMBEDDED_CONFIG = { /* 30个信源 */ };
const EMBEDDED_NEWS_DATA = { /* 45条新闻 */ };
```

#### 第2层：fetch API（备用）
- 内嵌数据不存在时自动尝试从JSON文件加载
- 兼容HTTP服务器部署模式

#### 第3层：默认配置（兜底）
- 前两层都失败时使用最小化默认配置
- 保证页面基本可用

### 代码修改清单

1. **js/app.js** - 核心逻辑修改：
   - 新增 `loadEmbeddedData()` 函数
   - 修改初始化流程：优先加载内嵌数据 → 备用fetch → 默认配置
   - 优化 `saveData()` 函数：支持localStorage本地存储
   - 新增 `downloadDataBackup()` 函数：一键下载JSON备份

2. **index.html** - 引入新文件：
   ```html
   <script src="js/embedded-data.js"></script>  <!-- 新增 -->
   <script src="js/app.js"></script>
   ```

3. **新增功能按钮**：【💾 备份数据】按钮
